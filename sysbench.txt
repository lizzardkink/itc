# Sysbench Setup for IDS Impact Analysis

**Purpose**: Bonus criterion (f) for up to 20 points
**Source**: https://github.com/akopytov/sysbench
**Type**: System benchmarking tool (CPU, memory, disk I/O)

## Installation

For Windows, sysbench needs to be built or use WSL:

Option 1 - WSL (Recommended):
```powershell
wsl --install
wsl
sudo apt-get update
sudo apt-get install sysbench
```

Option 2 - Build from source on Windows

## Benchmarks to Run

1. **CPU Test**:
   ```bash
   sysbench cpu --threads=4 --time=60 run
   ```
   Measures: events/second, execution time

2. **Memory Test**:
   ```bash
   sysbench memory --memory-total-size=10G run
   ```
   Measures: throughput (MB/s), latency

3. **Disk I/O Test**:
   ```bash
   sysbench fileio --file-test-mode=rndrw prepare
   sysbench fileio --file-test-mode=rndrw run
   sysbench fileio --file-test-mode=rndrw cleanup
   ```
   Measures: IOPS, throughput (MB/s)

## Testing Procedure

For each of 4 configurations (No IDS, AV, FW, AV+FW):
1. Restore VM snapshot
2. Run CPU benchmark (record events/sec)
3. Run memory benchmark (record MB/s)
4. Run disk I/O benchmark (record IOPS)
5. Repeat 3-5 times for consistency
6. Calculate average and percentage overhead vs baseline

## Rationale for Paper

"Sysbench provides standardized, reproducible benchmarks that measure system-level performance impact. Unlike application-specific tests, sysbench CPU/memory/disk benchmarks reveal how IDS software affects fundamental system resources, demonstrating the computational overhead of real-time scanning, network filtering, and signature matching operations."
